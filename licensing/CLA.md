# Contributor License Agreement

Hora is dual licensed: AGPL-3.0 for everyone, and a commercial license for
organisations that need different terms. That only works while one person holds
the rights to all of the code. If a contribution arrives under the AGPL alone,
nobody can include it in a commercially licensed build, and the project loses the
ability to ship to the Apple App Store, to sign an agreement with a school, or to
change license later.

This agreement keeps that possible. You keep the copyright to what you write.
You grant a license wide enough to keep dual licensing working.

Sign it once. It covers every contribution you make to Hora, past and future.

## If you are under 18

German law limits what minors can agree to on their own, and most Hora
contributors are students. If you are under 18, a parent or guardian has to
co-sign. Add their name and confirmation in the same place you add yours. Without
that, the contribution cannot be merged.

## How to sign

Add yourself to [contributors.md](contributors.md) in the same pull request as
your first contribution, using this line:

```
- Full Name <email>, GitHub @handle, signed YYYY-MM-DD
```

For contributors under 18, add a second line:

```
  Co-signed by <guardian full name>, guardian, YYYY-MM-DD
```

Opening the pull request with that line included means you accept this agreement.

## Why not a DCO

A Developer Certificate of Origin only certifies that you had the right to submit
the code under the project's existing license. It grants no right to relicense,
so it would not keep the commercial half of Hora alive. That is the one thing
this project needs from a contributor agreement.
